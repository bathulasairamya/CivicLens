# CivicLens Trained Model Artifacts

This directory stores serialized models generated by the benchmark training pipeline (`src/benchmark_runner.py`).

### Serialized Model Checkpoints:
1. **`tfidf_baseline_lr.joblib`**:
   - Feature extractor: Sublinear Word N-gram TF-IDF (`ngram_range=(1, 2)`)
   - Estimator: `LogisticRegression(class_weight='balanced')`
2. **`tfidf_char_svm.joblib`**:
   - Feature extractor: Character N-gram TF-IDF (`analyzer='char_wb'`, `ngram_range=(3, 5)`)
   - Estimator: `CalibratedClassifierCV(LinearSVC(class_weight='balanced'))`
3. **`semantic_classifier.joblib`**:
   - Feature extractor: Pretrained Multilingual Sentence Transformer (`paraphrase-multilingual-MiniLM-L12-v2`)
   - Estimator: Tuned Balanced Logistic Regression head operating over 384-dimensional dense vectors
   - Designed with lazy-loading state hooks for sub-50KB serialization and instant reproduction.
